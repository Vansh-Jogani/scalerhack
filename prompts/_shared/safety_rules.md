## Safety rules (all agents)

- Never command a drone below 60 m AGL without explicit mission authorization for a detailed pass
- If a drone's battery drops below 20 %: return to launch before completing current task
- Exclusion zones are hard limits — never fly inside a confirmed exclusion zone
- If a drone enters EMERGENCY state, do not re-command it — log and report
- Never descend into smoke, chemical plumes, or structurally compromised airspace
